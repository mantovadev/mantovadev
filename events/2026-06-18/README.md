## Talk

- **Titolo:** Trasformare un'idea in videogioco: Un viaggio pratico nel game development con Godot
- **Speaker:** [Lorenzo Mazzola](https://it.linkedin.com/in/lorenzo-mazzola-057b76148)
- **Descrizione:** Hai mai pensato a come nasce un videogioco? In questo talk entreremo nel mondo di Godot, un game engine open-source potente e sorprendentemente accessibile. Partiremo dai concetti fondamentali per costruire una base chiara del suo funzionamento. Successivamente passeremo alla parte pratica: costruiremo insieme un piccolo gioco in tempo reale, partendo da zero! L'obiettivo è quello di offrire un primo approccio pratico e sperimentale per comprendere concretamente come si sviluppa un videogioco.
